# zepto-ai-ml-capstone

This repository contains the three modules required for the Certificate Program in Artificial Intelligence and Machine Learning capstone project:

- **/data_pipeline** — Scraping, cleaning, and storing catalog data in SQLite.
- **/analytics** — Titanic dataset profiling, EDA, predictive modeling, and regression.
- **/support_assistant** — GenAI support assistant with Zepto policy corpus.
